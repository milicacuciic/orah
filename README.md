# Салаш Орах — сајт

Статички сајт (HTML, CSS и мало JavaScript-а), без библиотека и без build корака.

## Структура

```
index.html       почетна (рачунар)
jelovnik.html    јеловник (рачунар)
galerija.html    галерија (рачунар)
m/               исте три странице за телефон
images/          све фотографије
js/site.js       понашање: херо анимација, мени, честа питања,
                 утисци, форма за резервацију, јеловник на телефону
```

Сајт сам бира верзију: на екрану ужем од 768px отвара `m/`, на ширем верзију за рачунар.
Свака верзија се скалира на ширину екрана.

## Објављивање на GitHub Pages

1. Направи нов repository на GitHub-у (нпр. `salas-orah`).
2. Пребаци **садржај** ове фасцикле (не саму фасциклу) у repository: на GitHub-у „Add file → Upload files“, превуци све и потврди са „Commit changes“.
3. У repository-ју отвори **Settings → Pages**, под „Build and deployment“ изабери **Deploy from a branch**, грана `main`, фасцикла `/ (root)`, па **Save**.
4. После минут-два сајт је на адреси `https://<корисничко-име>.github.io/salas-orah/`.

За сопствени домен (нпр. salasorah.com): Settings → Pages → Custom domain, па у DNS подешавањима домена додај записе које GitHub прикаже.

## Пре него што сајт буде „прави“

- **Форма за резервацију** проверава датум и време (уторак, радно време), али поруку тренутно нигде не шаље.
  Најлакше је повезати бесплатан сервис, нпр. [Formspree](https://formspree.io): у `js/site.js` потражи коментар
  „ОВДЕ повезати слање“.
- **Google мапа**: у секцији Контакт је уграђена мапа по претрази „Салаш Орах, Кулски пут, Врбас“.
  За тачан пин узми код за уградњу са Google мапа (Подели → Угради мапу) и замени `src` у `<iframe>` у `index.html` и `m/index.html`.
- **ЋИР / LAT / EN** у навигацији су за сада само приказ — латинична и енглеска верзија не постоје.
- **Колачићи / Приватност** у подножју воде на `#`. Пошто форма прима име и телефон, треба додати кратку страницу о приватности.
- Фонтови се учитавају са Google Fonts (Cormorant Garamond и Lora).
